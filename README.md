# Nebula Docs (ideas and prototypes)

> [!NOTE]
> This vault collects ideas, earlier design variants and prototypes of how
> Nebula could develop. It is not documentation of the current code: many of
> the crates in `02-Crates/` (for example `nebula-cli`, `nebula-hub`,
> `nebula-ui`) and the GraphQL API described here are plans or past options,
> not something that exists in the main repository today.

The documentation of what is actually built lives in the main repository,
[vanyastaff/nebula](https://github.com/vanyastaff/nebula):

- [`AGENTS.md`](https://github.com/vanyastaff/nebula/blob/main/AGENTS.md) for the
  crate map, layer rules and commands;
- [`docs/`](https://github.com/vanyastaff/nebula/tree/main/docs) for the product
  canon, maturity table and quality gates;
- each crate's `README.md` under
  [`crates/`](https://github.com/vanyastaff/nebula/tree/main/crates).
